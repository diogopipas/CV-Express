Icon Placeholders
==================

This directory needs the following icon files:
- icon16.png (16x16px)
- icon32.png (32x32px)
- icon48.png (48x48px)
- icon128.png (128x128px)

These icons will be displayed in:
- Browser toolbar (16px, 32px)
- Extension management page (48px)
- Chrome Web Store (128px)

Icon Design Guidelines:
- Use the CV-Express logo/brand colors
- Keep it simple and recognizable at small sizes
- Use transparent background (PNG format)
- Follow Chrome Web Store icon guidelines

For now, you can create simple icons using:
1. Online tools like Canva, Figma, or Adobe Express
2. Use the CV-Express brand colors (teal/blue gradient)
3. Include a document/paper icon to represent CV/resume

Temporary Solution:
Create simple colored squares with the sizes above as placeholders
until professional icons are designed.
